# Built Environment and Transit Mode Choice: A Multimodal VLM Analysis

## Project Overview

This project examines how the built environment (BE) around trip origins and
destinations shapes transit mode choice in the Chicago metropolitan area. We
move beyond conventional predefined numeric metrics (the 5D framework) by
integrating satellite imagery, an urban concept taxonomy, and vision-language
models (VLMs). Post-Lasso logistic regression is used to select predictive
features from sociodemographics, 5D BE metrics, and VLM-derived image
principal components.

**Key findings:**
1. Satellite imagery consistently improves transit-use prediction through a
   long tail of statistically significant features.
2. Satellite-morphological descriptions dominate and complement the
   conventional 5D framework, linking homogeneous suburban form to lower
   transit use and transport infrastructure / mixed land use to higher use.
3. VLMs reveal context-specific features unique to Chicago (airports, coastal
   industrial zones, highway–light-rail mixtures), opening new avenues for
   travel behavior analysis.

**Paper:** *Vision-Language Models, Satellite Imagery, and Transit Ridership:
A Multimodal Built Environment Analysis*
