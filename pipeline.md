# Pipeline: Step-by-Step Execution Order

All notebooks are run from the project root using relative paths.
Run notebooks in the order listed below.

---

## Step 1 — `code/busstops.ipynb`

**Purpose:** Process transit stop locations and compute
distance-to-transit features at the census tract level.

| | Path |
|---|---|
| **Input** | Raw transit stop data in `raw_data/` |
| **Output** | Transit access features in `processed_data/` |

---

## Step 2 — `code/data_process_intergration.ipynb`

**Purpose:** Clean the MDT travel survey, filter trips, recode
variables, and integrate built environment features (EPA SLD,
OpenStreetMap, Chicago Open Data, transit access from Step 1)
into a baseline numeric trip-level dataset.

| | Path |
|---|---|
| **Input** | Raw survey files in `raw_data/survey/` |
| | Raw BE data in `raw_data/` |
| | Transit access features from Step 1 |
| **Output** | `processed_data/trips_with_be.parquet` |

**Key decisions:**
- Home-based trips only.
- Binary outcome: transit = 1, private vehicle = 0.
- Final analytic sample: 13,013 trips across 1,148 unique tracts.

---

## Step 3 — `code/imageforpoints.ipynb`

**Purpose:** Download satellite imagery for census tracts via
Mapbox API and generate VLM embeddings and PCA components for
origin and destination tracts.

| | Path |
|---|---|
| **Input** | `processed_data/trips_with_be.parquet` |
| | Mapbox API token (stored in `.env`) |
| **Output** | `raw_data/imagery/{tract_geoid}.png` |
| | `processed_data/embeddings/` |
| | `processed_data/trips_with_pca_{model_name}.parquet` |
| | `models/pca_{model_name}.pkl` |

**Key decisions:**
- Image extent adaptive to tract size.
- 100 PCA components retained per model.
- Eight VLM architectures used (CLIP, RemoteCLIP, DINOv3 variants).

---

## Step 4 — `code/tier3.ipynb`

**Purpose:** Build the three-tier urban concept taxonomy and
compute text embeddings for all concept phrases.

| | Path |
|---|---|
| **Input** | `raw_data/taxonomy/tier1_5d_phrases.txt` |
| | `raw_data/taxonomy/tier2_morphology_phrases.txt` |
| | Satellite imagery sample for Tier 3 generation |
| **Output** | `raw_data/taxonomy/tier3_datadriven_phrases.txt` |
| | `processed_data/concept_embeddings.npy` |
| | `processed_data/concept_metadata.csv` |

**Key decisions:**
- Tier 1 (20 phrases): 5D framework literature.
- Tier 2 (20 phrases): satellite morphological concepts.
- Tier 3 (60 phrases): generated by InternVL3-78B from imagery,
  then deduplicated.

---

## Step 5 — `code/final_postlasso.ipynb`

**Purpose:** Run post-Lasso logistic regression for all VLM
specifications and the sociodemographic-only baseline.
Report model fit statistics.

| | Path |
|---|---|
| **Input** | `processed_data/trips_with_pca_{model_name}.parquet` |
| **Output** | `models/postlasso_{model_name}.pkl` |
| | `tables/regression_coefficients_{model_name}.csv` |
| | `tables/model_fit_statistics.csv` |
| | `tables/regression_main_table.tex` |

**Key decisions:**
- Stratified 80/20 train–test split (train N = 10,410; test N = 2,603).
- Lasso penalty C = 0.02, selected via cross-validation.
- Post-Lasso step uses unpenalized logistic regression for inference.

---

## Step 6 — `code/vis_final.ipynb`

**Purpose:** Interpret significant imagery PCs via concept
alignment, retrieve representative satellite images, generate
LLM behavioral reasoning, and produce all publication-ready
figures and tables.

| | Path |
|---|---|
| **Input** | `models/postlasso_{model_name}.pkl` |
| | `processed_data/concept_embeddings.npy` |
| | `processed_data/concept_metadata.csv` |
| | `models/pca_{model_name}.pkl` |
| | `raw_data/imagery/*.png` |
| **Output** | `tables/pc_concept_alignment.csv` |
| | `tables/pc_interpretation_table.tex` |
| | `figures/*.pdf / *.png` |
